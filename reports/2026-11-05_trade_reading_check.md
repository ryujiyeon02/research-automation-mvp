# BEA 국제무역 발표 누락 보완과 로컬 모델 읽기 실험

확인일: 2026-11-05. 11월 4일 보고서에서 BEA는 GDP 발표만 수집했습니다. 국제무역 발표는 보고서 기준 시각 이전인 11월 4일 22:30 KST에 공개됐지만 누락했습니다. 현재 실행기는 명시한 URL 목록을 읽으며 BEA 발표 일정 전체에서 새 자료를 자동 발견하지 않습니다. 이번에 원문을 별도 수집했으며 당시 수집한 것으로 소급하지 않았습니다.

BEA·Census의 9월 상품·서비스 적자는 1,050억 달러로 8월 수정치 1,057억 달러보다 감소했습니다. 다만 Census 기준 실질 상품 적자는 증가했습니다. 범위·가격 조정·금 조정이 달라 단일 헤드라인에서 분기 GDP 기여를 확정할 수 없습니다. [공식 발표](https://www.bea.gov/news/2026/us-international-trade-goods-and-services-september-2026)

## 실제 로컬 모델 호출

현재 설치된 `qwen3.5:9b`에 원문 발췌와 고정 질문을 주었습니다. 헤드라인 수치, BOP·Census 및 명목·실질 구분, 3분기 GDP 기여에 관한 결론 가능 여부를 한국어 JSON으로 답하도록 요청했습니다. 새로운 의미 검증 루프를 구현하거나 다른 모델을 설치한 것은 아닙니다.

| 확인 항목 | 저장된 응답과 원문의 대조 결과 |
| --- | --- |
| 적자·수출입 헤드라인 수치 | 원문과 일치 |
| 서로 다른 통계 기준의 세부 수치 연결 | 오류 발견. BOP 상품 적자 1,359억 달러와 7억 달러 감소를 Census 명목 상품 적자 항목에 연결하고 증가로 기술 |
| 이 문서만으로 분기 GDP 순수출 기여 개선을 확정하는가 | 확정할 수 없다고 답변 |
| 한국어 응답 요청 | 지키지 않고 영어로 응답 |

입력 1,460토큰, 출력 441토큰이었고 실제 호출은 약 51초 걸렸습니다. 원문·입력·모델 응답·검토 결과를 `data/research_runs/2026-11-05/bea_trade/`에 보존하고 사용량을 DB에 기록했습니다. 원문은 문서 ID 23입니다.

이 검토는 Codex가 수행했습니다. 한 문서에 구분할 항목을 미리 지정한 단 한 번의 실험이며 독립된 전문가 평가나 모델 정확도 벤치마크가 아닙니다. 기존 Codex 브리핑과 동일한 입력·조건의 비교 실험도 아니므로 모델 간 성능 순위로 해석하지 않습니다.

## 현재 판단
