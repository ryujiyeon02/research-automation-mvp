# 1차 아키텍처

## 목표

경제 뉴스·정책 보고서·기업공시에서 출처가 추적되는 인과 주장을 추출하고, 공식 시계열과 시장 반응을 별도로 결합합니다.

```text
공식 API/RSS/공시
      │
      ▼
수집·중복 제거·원문 보존 ── documents
      │
      ▼
관련 문단 선택
      │
      ▼
CLOVA 구조화 추출 ───────── causal_claims
      │                         │
      │                         ├─ 원문 근거
      │                         ├─ 출처·발표시각
      │                         ├─ 확실성·시차
      │                         └─ 검증 상태
      ▼
ECOS/FRED/KRX/증권사 수치 ─ observations / market_prices
      │
      ▼
비교·이벤트 분석·데일리 브리핑
```

## 모듈 경계

- `collectors`: 외부 데이터 소스를 내부 문서 형식으로 변환
- `llm`: 모델 공급자와 프롬프트·스키마 관리
- `db`: SQLite 저장 및 중복 방지
- `models`: 공통 데이터 구조와 검증 규칙
- `cli`: 수집·진단·추출의 명시적 실행 진입점

## 비용 절감 규칙

1. 문서 URL과 내용 해시로 중복 호출을 차단합니다.
2. HTML 정리, 날짜·종목코드·수치 파싱은 LLM 없이 수행합니다.
3. 긴 문서는 관련 문단만 선별하고 입력 글자 수를 제한합니다.
4. 출력은 고정 JSON 스키마로 제한합니다.
5. LLM이 반환한 근거 문장이 실제 입력에 없으면 해당 주장을 폐기합니다.
6. 같은 문서·같은 프롬프트 버전의 결과는 재사용합니다.
7. 일별 보고서는 개별 문서 요약 결과를 모아 하루 한 번 생성합니다.
8. 요청별 입력·출력 토큰을 `llm_usage`에 기록합니다.

## 신뢰성 경계

- `causal_claims`는 문서 작성자가 주장한 인과관계입니다.
- 원문에 명시되지 않은 중간 경로는 생성하지 않습니다.
- `confidence`는 모델 확신도이며 진실 확률이 아닙니다.
- 최신 지표 값과 수치 계산은 공식 API와 결정론적 코드로 처리합니다.
- 검증 상태는 `reported_claim → data_checked → analyst_reviewed` 순으로 승격합니다.
