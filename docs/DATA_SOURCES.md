# 데이터 소스 명세

## 1차 연결

| 영역 | 소스 | 인증 | 역할 |
|---|---|---|---|
| 미국 공시 | SEC EDGAR | API 키 없음, User-Agent 필요 | 10-K·10-Q·8-K 목록과 원문 |
| 문서 분석 | Ollama + `qwen3.5:9b` | 로컬 실행, API 키 없음 | 명시적 인과 주장 구조화 |

## 2차 연결

| 영역 | 소스 | 역할 |
|---|---|---|
| 국내 공시 | OpenDART | 사업·분기보고서, 주요사항, 재무정보 |
| 국내 시장 | KRX Open API | 공식 일별 주가·지수·ETF·시장 통계 |
| 국내 거시 | ECOS | 금리·환율·물가·통화·국민계정 |
| 해외 거시 | FRED/ALFRED | 해외 시계열과 빈티지 데이터 |
| 증권사 시세 | 메리츠증권 Open API (구현, 읽기 전용) | 국내 일봉·투자자별 순매수, 해외 일봉·분봉 |
| 실시간 시세 | 한투·키움·토스 중 한 곳 | 현재가·호가·계좌, 이후 필요 시 주문 분리 |

## 수집 공통 규칙

- 원문과 정제문을 구분해 보존합니다.
- 소스 문서 ID, 원문 URL, 발표시각, 수집시각을 저장합니다.
- 수정 공시는 기존 문서를 덮어쓰지 않고 식별 가능한 버전으로 관리합니다.
- 각 제공기관의 호출 한도와 재배포 제한을 준수합니다.
- API 키와 계좌 식별정보는 `.env`에만 저장합니다.
